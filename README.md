# Stitch Shaper

Stitch Shaper is a browser tool for planning crochet increases and decreases
with clear, stitch-perfect shaping calculations.

## Use it

Open [Stitch Shaper](https://stitch-shaper.dracars.com/) in your browser.

## Run it locally

The app is a static browser project. Serve the `public/` directory with any
local static server, then open it in a browser. The test suite can be run with:

```bash
npm install
npm test
```
